goober.auto

Small helpers for timed scripts. This page follows gooberc/libs/auto.md.

use goober.auto
  • sleep N pauses for about N milliseconds. The stub yields desktop frames
  • print "..." writes to the console, shared with goober.console
  • exit terminates the app

Scheduling, event loops, and a richer automation language are still ahead. Keep scripts short. Long sleeps are clamped by the runtime stub.
