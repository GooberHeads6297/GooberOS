KEY_* names are integer literals. They match the codes from getkey and the keyboard driver. A variable with the same name wins over the built-in. This page follows gooberc/libs/keys.md.

Letters and digits

KEY_A through KEY_Z are the lowercase codes delivered when unshifted. KEY_W is 119, the same as 'w'. getkey may return uppercase when Shift is held. keyheld KEY_W still reports held for either case.

KEY_0 through KEY_9 are the digit character codes.

getkey and keyheld

  • getkey returns one pending press, or 0. It pumps a desktop frame.
  • keyheld k is 1 if that code is currently down, on PS/2 or USB. It does not consume the press queue. Use it for WASD-style loops.
use goober.gui
app gui

window "Keys" 360x160
while winclosed == 0
  var k = getkey
  if k == KEY_ESC
    exit
  end
  fill NAVY
  if keyheld KEY_W
    label 16 40 "W held" LIME NAVY
  end
  if keyheld KEY_A
    label 16 60 "A held" LIME NAVY
  end
  present
  sleep 16
end
exit
