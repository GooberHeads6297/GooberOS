Console I/O and the core language builtins. This page follows gooberc/libs/console.md.

use goober.console

Operations

FormMeaning
print "..." / print <expr>Write to the console
exitTerminate
len xLength of a string, list, or map
slice s a bSubstring [a, b)
find hay needleIndex of a substring, or -1
alloc n / free pHeap blob
mapEmpty string-keyed map
get / set / pushList or map access
typeof v0 int, 1 str, 2 list, 3 blob, 4 map
errmsgLast runtime error string

Control

fn / call / return, and if / while / for / break / continue.

Keep the line-oriented end block style. After a failed read, listdir, or set, check errmsg. The full write-up is the language page.
