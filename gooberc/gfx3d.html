goober.gfx3d

Tour Language Console GUI Files Keys Colors DOS Auto 3D License

Software 3D for GooberC windows: a camera, model transforms, flat-shaded solids, wireframes, and simple shapes. It uses integer math only, with no FPU. The scene draws onto the same canvas as fill, rect, and label, so 2D text mixes with 3D. This page follows gooberc/libs/gfx3d.md.

use goober.gfx3d
app gfx3d
window "Spin" 480x400

A window is required. Drawing goes to the most recent window.

Coordinates

  • World units are plain integers. x points right, y up, and z away from the default camera
  • Angles are whole degrees. scale3d takes percentages, so 100 is 1x
  • GooberC reads move3d 0 -50 0 as 0 - 50 0. Write a negative argument as (0 - 50) or keep it in a variable

Frame loop

  • fill color or clear 0xRRGGBBAA starts a frame. Both clear the 2D draw list and the 3D scene. clear ignores the alpha byte
  • Draw the 3D shapes, then any rect or label on top
  • present shows the finished frame. The window never shows half a frame. If you skip present, the frame appears at the next getkey, sleep, or wait

2D commands issued before the first 3D shape of a frame draw behind the scene. Commands issued after it draw on top.

Camera and light

FormMeaning
camera3d x y z yaw pitchPlace the camera. At yaw 0 and pitch 0 it looks toward +z. Positive yaw turns right, positive pitch looks up. Default camera3d 0 0 (0 - 300) 0 0
fov3d degHorizontal field of view, 10–170. Default 60
light3d x y z ambientDirection toward the light, and the ambient level in percent. Default light3d (0 - 40) 70 (0 - 60) 30

Model transform

Each call changes the current transform. The last call applies to vertices first, the same order OpenGL uses: move3d and then turn3d spins a shape in place at its new position.

FormMeaning
reset3dBack to identity
move3d x y zTranslate
turn3d ax ay azRotate about X, then Y, then Z, in degrees
scale3d sx sy szScale by percentages
push3d / pop3dSave and restore the transform, 8 levels deep

Shapes

Every shape is centered on the current model origin.

FormDraws
cube3d size colorA solid cube with edge size
pyramid3d size colorA square pyramid, size wide and tall
plane3d size colorA two-sided square in the XZ plane at y = 0
grid3d size cells colorA wireframe floor grid in the XZ plane
tri3d x1 y1 z1 x2 y2 z2 x3 y3 z3 colorA two-sided triangle
line3d x1 y1 z1 x2 y2 z2 colorA 3D line
wire3d on1 draws shapes as outlines. 0 goes back to solid shading

Solid faces are flat-shaded from light3d. Cubes and pyramids skip their back faces. Depth uses the painter's algorithm: each frame's faces are sorted far to near before drawing. That is exact for separate convex shapes, but large faces that cross each other can sort wrong. Faces behind the camera are clipped at the near plane. A frame holds up to 1024 triangles and lines.

Math helpers

  • sin deg and cos deg return the value times 1024, so sin 30 is 512. Multiply first, then divide: r * (cos a) / 1024
  • projx x y z and projy x y z return the window position of a model-space point, or -1 if it is behind the camera. Use them to place a label next to a 3D object

A variable or fn you define with one of these names wins over the builtin. Wrap a builtin call in parentheses when more math follows it, as in (sin a) * r / 1024.

Example

use goober.gfx3d
app gfx3d
window "Spin" 480x400
var a = 0
while winclosed == 0
  fill NAVY
  camera3d 0 120 (0 - 360) 0 (0 - 18)
  reset3d
  push3d
  move3d 0 (0 - 80) 0
  grid3d 600 10 DARKGRAY
  pop3d
  turn3d a a / 2 0
  cube3d 120 ORANGE
  label 8 8 "angle " + str a INK NAVY
  present
  a = a + 3
  sleep 16
end

The full demo is gooberc/examples/Cube3D.gc. It installs as Apps/Cube3D.gob, with its source in Apps/src/Cube3D.gc. Hold the arrow keys to orbit, press W for wireframe, and press Space or click to pause. Flat 2D windows use goober.gui.
