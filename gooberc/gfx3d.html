goober.gfx3d

Tour Language Console GUI Files Keys Colors DOS Auto 3D

Reserved 3D and canvas module. The opcodes compile today. Drawing is still a stub. This page follows gooberc/libs/gfx3d.md.

use goober.gfx3d
  • clear 0xRRGGBBAA is reserved to clear a canvas. It does not draw yet
  • print "..." can leave a console note while you prototype
  • exit terminates

Planned

  • Create a canvas and present a frame
  • Mesh and camera helpers
  • A software or GPU raster path

Use use goober.gfx3d and clear so samples stay forward-compatible. Do not assume pixels are drawn yet. Two-dimensional windows use goober.gui.
