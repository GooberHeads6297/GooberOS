GooberC language

Tour Language Console GUI Files Keys Colors DOS Auto 3D

GooberC is a line-oriented language for GooberOS apps. Keywords, optional indentation, blocks closed with end, and very little punctuation. .gob version is 2. Version 1 bytecode is rejected.

This page follows gooberc/SPEC.md.

Statement forms include write path data, push list val, and set container key val.

Expressions

Integers, names, string and list literals, + - * /, parentheses, and comparisons == != < <= > >=. Globals are limited to 128. Each frame has at most 32 locals.

use goober.console
use goober.fs

fn greet name
  print "hi "
  print name
end

var n = 3
while n > 0
  call greet "tick"
  n = n - 1
end

var data = read "Config/settings.cfg"
if data
  print len data
end
exit

Left out on purpose

C types, braces, semicolons, ->, headers, int main(void), and pointer arithmetic are not part of the language.

Surface words fill, rect, label, present, num, millis, and keyheld compile to those opcodes, as do the 3D words on the 3D page. Hex literals (0xRRGGBB) are accepted. Call arguments bind so mod x 10 == 9 means (mod x 10) == 9. Statement arguments are full expressions, so write a negative argument as (0 - n).

The virtual machine has an operand stack of 128, 128 globals, 64 frames with 32 locals, and an object table with about 128 KB of heap. Lists grow to at most 256. Object handles set bit 31. A value only counts as an object when it names a live one, so negative ints add and print normally. Runtime errors set errmsg. A version mismatch says which version was expected.

GUI windows are double-buffered. Drawing edits a back frame that present, or the next getkey, sleep, or wait, publishes. The VM also services the desktop from loop back-edges and from winclosed, clicked, and keyheld about every 16 ms, so the pointer stays live in any loop.
