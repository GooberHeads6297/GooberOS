Filesystem and path builtins. This page follows gooberc/libs/fs.md. Volume choice and limits are on the Documentation page.

use goober.fs
FormResult
exists path1 if the path exists, otherwise 0
read pathFile contents as a string, or 0 on failure
write path dataWrites the string data
listdir pathA list of entry names, or 0 if the path is missing
path_join a b"a/b", with slashes handled
dirname p / basename pPath split
 
use goober.console
use goober.fs

var dir = path_join "Apps" "src"
var names = listdir "Apps"
if names
  var i = 0
  while i < len names
    print get names i
    i = i + 1
  end
end
exit

Errors

On failure, check errmsg, or a return value of 0.

GooberDOS shared folder

Guest C:\ maps to host /Dos. Copy files into /Dos or /Dos/Apps, then run them with a double-click, rundos, or dos_run. See DOS.
