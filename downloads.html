Boot it

Write the ISO to a USB drive with balenaEtcher or Rufus, or attach it as a virtual optical drive. It boots on BIOS and UEFI. The system requirements list the PC, the USB drive, and the disk the installer can erase. From the live desktop, open the installer, or use the shell:

install list
install fat32 <target-id> YES GPT

YES GPT is for UEFI. Use YES MBR for a legacy BIOS disk. Then reboot from that disk.
