GooberOSx86-x64.iso 64-bit. Use this on current PCs. GooberOSx86.iso 32-bit. Use this on older machines.

Boot it

Write the ISO to a USB drive, or attach it as a virtual optical drive. It boots on BIOS and UEFI. From the live desktop, open the installer, or use the shell:

install list
install fat32 <target-id> YES GPT

YES GPT is for UEFI. Use YES MBR for a legacy BIOS disk. Then reboot from that disk.
