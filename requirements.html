System requirements

Filesystems Requirements The PC balenaEtcher Rufus

GooberOS boots from a live ISO on a BIOS or UEFI PC. balenaEtcher and Rufus write that ISO to a USB drive. The installer inside the live desktop is what copies GooberOS onto a disk.

The PC

PartWhat it needs
Processor An x86-64 PC for GooberOSx86-x64.iso. An older 32-bit PC for GooberOSx86.iso.
Firmware Legacy BIOS or UEFI. Turn UEFI Secure Boot off. The ISO is not signed for Secure Boot.
Memory 64 MB of RAM. The kernel keeps a 16 MB working area for the desktop and programs, and 8 MB of that can hold a DOS program.
Display A graphical screen the firmware can set, 800×600 or larger, at 15, 16, 24, or 32 bits per pixel. BIOS uses VESA. UEFI uses the GOP framebuffer.
Keyboard and mouse PS/2 or USB. The desktop uses the mouse. The shell can be driven from the keyboard.
Live USB A USB drive larger than the ISO, which is about 55 MB. A 1 GB drive is a comfortable choice. Writing the image erases that drive.
Install disk A second disk you can erase: ATA, SATA, NVMe, SD or eMMC, or another USB drive. A FAT32 install needs about 40 MB. GooberFS needs about 8 MB more. A 1 GB disk is a comfortable target.

The USB drive is the live system. Boot it, then open the installer and choose the internal disk. The installer erases the whole target. Partition style and FAT32 or GooberFS are chosen there, which is covered on the filesystem page.

A virtual machine can boot the ISO as a virtual disc. That path skips Etcher and Rufus. Give the machine the same CPU type as the ISO, 64 MB of RAM or more, and a virtual disk of 1 GB or more.

balenaEtcher

Use Etcher when you want the fewest choices. It runs on Windows, macOS, and Linux, and it writes the hybrid ISO as a single image. That image boots on BIOS and on UEFI.

  1. Download GooberOSx86-x64.iso or GooberOSx86.iso from the Download page.
  2. Open balenaEtcher and choose Flash from file. Select the ISO.
  3. Choose the USB drive. Etcher erases the drive you select.
  4. Flash the image, then boot the PC from that USB drive.

This is the right tool for a first USB stick, for a lab machine, or when you are not on Windows. You do not pick MBR or GPT in Etcher. Those choices belong to the GooberOS installer, after the machine has booted the stick.

Rufus

Use Rufus when you are on Windows and you want to see the target drive and the write mode before anything is erased. Rufus asks how to write a hybrid ISO. Choose DD Image mode. That writes the ISO byte for byte, so the BIOS and UEFI boot records stay as GooberOS built them.

  1. Download the ISO from the Download page.
  2. Open Rufus and select the USB drive under Device.
  3. Select the ISO as the boot selection.
  4. When Rufus asks about the write mode, choose DD Image mode.
  5. Start. Rufus erases the selected drive. Boot the PC from that USB drive.

ISO mode in Rufus rebuilds the stick as a new disk. Use DD Image mode for this ISO so the hybrid layout remains. The MBR or GPT choice for the installed system is still made later, inside the GooberOS installer, on the disk you install to.

SituationUse
